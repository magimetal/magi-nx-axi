## [0.1.0] - 2026-08-03

### Added

- Initial public release of the self-contained `magi-nx-axi` CLI for Nx workspace, Nx Console IDE, and Nx Cloud operations.
- Nx MCP-equivalent documentation, plugin, workspace, project, generator, graph, task, CI, task-output, and self-healing capabilities plus recent CIPE inspection.
- Compact TOON output by default, strict JSON output on request, structured errors, explicit empty states, bounded truncation, and non-interactive execution.
- Opt-in Claude Code, Codex, and OpenCode session integrations with preserving, idempotent setup.
- crates.io packaging and tagged GitHub binary releases for Linux x86_64 and macOS x86_64/ARM64.
